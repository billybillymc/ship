How the Graph Makes Decisions

Three things to watch in every trace

1. Execution Path

Which nodes ran, which were skipped, and why. Different triggers activate different fetch nodes and routing edges.

Event → Project + Person fetch
Scheduled → + Program fetch
Coach → Person + History fetch

2. Human Decision Point

Where the agent stops and waits. Every data mutation lands in an action queue — approve, dismiss, or snooze.

Mutation proposed → WAIT
Read-only output → SEND

3. Deterministic vs AI

Thresholds are math — zero cost, instant, unit-testable. Gemini explains why, never decides what.

Threshold: >7 high = violation
Gemini: "because scope creep..."

Test 2: PM Alert — In-Progress Overload Event

Setup

Issue status changed on Payment Integrity. Now 6 in-progress (threshold: 5).

Execution Path

Trigger → User → [Project || Person] → Threshold (1 violation) → Gemini (PROACTIVE_VIOLATIONS) → Suggestion Gen → Notification

What to See in the Trace

  • Only 2 fetch nodes — no Program Fetch (event-driven)
  • Threshold outputs: in_progress_overload, severity score
  • Gemini mode flips to PROACTIVE_VIOLATIONS
  • Suggestion Generator fires — maps violation to action

Human Decision: Approve / Dismiss / Snooze

PM sees: "Move [issue] back to todo — 6 items in progress exceeds WIP limit of 5."

  • Approve → PATCH executes → WebSocket event → agent re-evaluates after 30s
  • Dismiss → archived, won't resurface unless count worsens
  • Snooze 24h → lifecycle cron re-checks after expiry
Result: 1 violation detected, 1 suggestion generated with specific issue ID.

Test 5: Project Kickoff On-Demand

Setup

Execution Path

Three Architectural Bets

Deterministic Thresholds + AI Explanation

The agent never decides what to do based on Gemini output. Thresholds decide. Gemini explains why.

Auditable. Testable. 19 threshold unit tests with zero mocks.

Single Graph, Multiple Paths

One StateGraph with conditional edges. No "simple mode" shortcuts. Every run produces a trace showing the path taken.

8 Gemini modes. 6 distinct execution paths. 1 graph definition.

Suggest, Never Execute

Every mutation goes through the action queue. The agent surfaces information. The human decides.

Approve · Dismiss · Snooze — per-suggestion granularity.
